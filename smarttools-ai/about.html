About SmartTools AI

Tools that solve real problems — not just another chat box.

What we build

SmartTools AI is a collection of free, focused tools for everyday tasks: removing backgrounds, summarizing PDFs, building resumes, generating quizzes, writing emails, converting units, text-to-speech, and more.

Most tools run entirely in your browser so your files stay private. AI-powered tools use Google Gemini through a secure server proxy — you never need to supply an API key.

Privacy-first

We designed the site so that sensitive data (PDFs, images, personal notes) is processed on your device whenever possible. History and preferences live only in your browser’s localStorage.

Free to use

All tools are free. Soft daily limits help keep AI costs sustainable. The site is supported by optional advertising (Google AdSense) once approved.

Technology

Static frontend hosted on Cloudflare Pages, AI via a Cloudflare Pages Function proxy to Gemini, client-side libraries (PDF.js, jsPDF, Web Speech API) for local processing.
