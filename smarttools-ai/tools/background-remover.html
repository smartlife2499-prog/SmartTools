How to enable real AI removal

For production, add the library (works fully client-side after model download ~30 MB, then cached): 

npm install @imgly/background-removal onnxruntime-web

import { removeBackground } from '@imgly/background-removal';
const blob = await removeBackground(imageFile);
// then display / download the transparent PNG

No server, no API key, files never leave the browser. Perfect match for SmartTools AI’s privacy-first approach.
